## ✨ Features

| Feature | What it does |
|---|---|
| 🔨 **Auto Mace** | Smash-attacks players while you fall, with random delays. Swaps to the mace early and back afterwards. |
| 🧿 **Pearl Catch** | One key: throws an ender pearl, then a wind charge. |
| 🪽 **Elytra Swap** | One key: switches between your chestplate and elytra. |
| 💨 **Auto Wind Charge** | One key: looks down, jumps and throws a wind charge. |
| ⚙️ **Config menu** | Toggles, sliders and rebindable keys, saved automatically. |

## 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for **Minecraft 1.21.1**.
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for 1.21.1.
3. Download the latest `.jar` from [Releases](https://github.com/ImNotGemsDc/Auto-Mace-Legit/releases) (**not** the `-sources` one).
4. Put both `.jar` files in your `mods` folder and launch the game.

## 🎮 Usage

- Press **Right Shift** to open the menu (rebindable in Controls).
- **Auto Mace** tab: toggles
